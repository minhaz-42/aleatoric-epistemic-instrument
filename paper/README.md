# paper/

Empty of prose by design, and it should stay that way for now.

`research/02_novelty_analysis.md` opens by recording that no literature has been verified and that
nothing may be written up before that changes. Drafting a paper here while every prior-art statement
in the project is marked `[U]` would contradict the project's own stated rule, and would anchor the
framing before the one question that determines it — whether the headline is a finding or a
replication — has been asked.

`paper/figures/` is populated by `scripts/make_figures.py` and is safe to regenerate at any time.

See `research/03_research_decision.md` for what has to happen first.
